# 双语文档规范

英文沿用原文件名，简体中文配对使用.zh-CN.md。发布展示用README、展示页、架构、
复现、验收、运维、路线和索引均登记在languages.json；两种语言互链，同一变更一起维护。

事实、能力状态、范围/版本、验证边界和命令块必须一致。命令块刻意保持完全相同，
包括变量及占位符。检查器验证配对存在、双向导航、Shell块一致和本地链接；
翻译事实是否等价仍需人工审阅。

历史报告、原始日志出处、档案及专题基线参考可保留原始语言，
由双语展示/证据账本汇总；不改原始证据或扩大验证结论。
个人学习笔记和秘密不因翻译而公开。

```bash
python3 scripts/check_repository.py
python3 -m unittest discover -s tests -v
```

离线检查不验证GPU部署或翻译语义。区分操作者真实观察、历史来源、生成配置和
离线验证的公开工具。不能因有译文或模拟测试就宣称新GPU已实测通过。
