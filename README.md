# SGLang Serving Lab

A production-oriented LLM inference serving platform built with
SGLang, Docker, Prometheus, and Grafana.

## Current Features

- Qwen3-0.6B inference using SGLang
- OpenAI-compatible inference API
- CUDA Graph optimization
- Prometheus metrics collection
- Grafana monitoring
- Concurrency and prefix caching benchmarks

## Roadmap

- [x] Single-GPU inference serving
- [x] Prometheus and Grafana integration
